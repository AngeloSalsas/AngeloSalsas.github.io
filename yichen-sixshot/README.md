# SixShot

A p5.js / Web Audio project by Yichen Liu.

## Files
- `index.html` loads p5.js, p5.sound, and the project code.
- `sketch.js` contains the full SixShot game.

## How to publish with GitHub Pages
1. Create a new GitHub repository, for example `sixshot`.
2. Upload `index.html` and `sketch.js` into the repository root.
3. Go to `Settings > Pages`.
4. Under `Build and deployment`, choose `Deploy from a branch`.
5. Select branch `main` and folder `/root`.
6. Save.
7. GitHub will give you a website link, usually:
   `https://YOUR_USERNAME.github.io/sixshot/`

## Important
In `sketch.js`, replace this placeholder:

`https://YOUR_USERNAME.github.io/sixshot/`

with your real GitHub Pages link after GitHub creates it.

## Demo flow
- Open the GitHub Pages link.
- Click anywhere once to enter fullscreen and start audio.
- Click START to begin the game.
